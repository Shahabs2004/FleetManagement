# سامانه مدیریت ناوگان

سامانه تحت وب مدیریت ناوگان حمل‌ونقل سازمانی، با رابط کاربری فارسی و استقرار در شبکه داخلی سازمان.

## وضعیت توسعه

پروژه در مرحله توسعه فعال ماژول‌های اصلی قرار دارد. در شاخه توسعه، زیرساخت راه‌اندازی اولیه، احراز هویت AD و مدیر اضطراری، نقش‌ها و مجوزها، مدیریت کاربران، رانندگان و خودروها، گردش مأموریت، چاپ دستور، اعلان داخلی، گزارش‌گیری، ممیزی، سوابق نشست، داشبورد و جدول زمانی رانندگان پیاده‌سازی شده‌اند.

صف پایدار پیامک، ساخت پیام از رویدادهای مأموریت، قالب‌ها و قواعد گیرندگان، گزارش پیامک و تلاش مجدد دستی با ثبت علت اصلاح پیاده‌سازی شده‌اند. اتصال واقعی SOAP، پردازشگر ارسال خودکار، تلاش مجدد پس‌زمینه و استعلام تحویل هنوز به تأیید قرارداد WSDL ارائه‌دهنده و آزمون عملی نیاز دارند. این نسخه هنوز برای بهره‌برداری سازمانی تأیید نشده و باید آزمون IIS، AD/LDAPS، SQL، امنیت و بار در محیط واقعی را بگذراند.

## فناوری‌های پایه

- .NET 10 LTS و C# 14
- Blazor Web App با حالت Interactive Server
- Clean Architecture به‌صورت Modular Monolith
- Entity Framework Core 10
- SQL Server
- استقرار روی Windows Server و IIS

## اصول توسعه

- تفکیک مسئولیت‌ها و کوچک نگه‌داشتن کلاس‌ها و فایل‌ها
- ثبت توضیحات و کامنت‌های فارسی در کد
- جداسازی ماژول‌های کسب‌وکار
- ثبت تغییرات در Git با Commitهای کوچک و معنادار
- عدم ثبت اطلاعات محرمانه، رمزها و نسخه‌های پشتیبان در مخزن

## هشدار امنیتی

این مخزن عمومی است. هیچ رمز واقعی SQL Server، اطلاعات اتصال Active Directory، اطلاعات سرویس پیامک، داده واقعی کاربران یا نسخه پشتیبان پایگاه داده را در این مخزن قرار ندهید. فایل‌های تنظیمات محلی و محیط عملیاتی باید خارج از کنترل نسخه نگهداری شوند.
