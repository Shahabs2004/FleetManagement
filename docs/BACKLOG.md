# کارهای باقی‌مانده (به ترتیب اولویت)

بر اساس بررسی کد در `docs/SPEC.md` بخش ۱۷. هر مورد یک PR کوچک.

## P0 — صحت و ایمنی
1. آزمون یکپارچه با SQL Server (LocalDB/Testcontainers): تداخل راننده/خودرو هم‌زمان، فاصله اجباری، شماره‌گذاری سالانه بدون تکرار.
2. آزمون‌های جریان کامل: تقسیم، انصراف (تأیید/رد/انقضا)، درخواست تغییر اتمی، پیوستگی کیلومتر.
3. [x] تأیید قواعد پیوست پ: Pending/UnderReview با لغو مستقیم درخواست‌کننده بسته می‌شود؛ انصراف فقط از Confirmed/Running ثبت می‌شود؛ لغو مدیریتی از WithdrawalPending نیز مجاز است.
4. [x] بررسی RowVersion و Constraint در Migrationها؛ زنجیره ۱۳ Migration روی SQL Server خالی اعمال می‌شود، Snapshot با مدل جاری تطبیق دارد و آزمون‌های RowVersion/Constraint موفق‌اند.

## P1 — معماری
5. [x] تکمیل انتقال سناریوهای مأموریت به Application و تبدیل `MissionManagementService` به facade. قواعد، تمدید، مسیرهای ثبت/ویرایش/بررسی درخواست، مدیریت تغییر مأموریت، کیلومترشمار، تقسیم، انصراف و پردازش چرخه‌عمر در Application اجرا می‌شوند؛ دسترسی EF Core و تراکنش‌ها در آداپتورهای Infrastructure باقی مانده‌اند.
6. [x] شکستن `FleetAuthenticationEndpoints` به فایل‌های تک‌مسئولیتی برای مسیرهای Directory، Local Administrator و Windows؛ CI در PR شماره ۳۱ (Ubuntu، Windows و SQL Server) موفق بود.
7. تغییر نام پروژه آزمون یا جداسازی آن به Domain/Application/Infrastructure/Integration.
8. کاتالوگ مرکزی مجوزها (ثابت‌ها) + ثبت مجوزهای مستقل مذکور در پیوست ب.

## P2 — قابلیت
9. به‌روزرسانی زنده تایم‌لاین/فهرست‌ها با SignalR.
10. تأیید/پیاده‌سازی ذخیره PDF حکم (RTL، فونت فارسی) و قالب قابل تنظیم.
11. نگاشت وضعیت‌های تحویل ADP پس از دریافت نمونه واقعی.
12. بازبینی ۸ گزارش و خروجی‌ها نسبت به بخش ۱۱.
