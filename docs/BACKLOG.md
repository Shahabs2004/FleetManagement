# کارهای باقی‌مانده (به ترتیب اولویت)

بر اساس بررسی کد در `docs/SPEC.md` بخش ۱۷. هر مورد در یک PR کوچک انجام می‌شود.

## P0 — صحت و ایمنی
1. آزمون یکپارچه با SQL Server (LocalDB/Testcontainers): تداخل راننده/خودرو هم‌زمان، فاصله اجباری، شماره‌گذاری سالانه بدون تکرار. **به تعویق افتاده با تصمیم کاربر؛ بررسی در محیط عملیاتی انجام می‌شود و در صورت گزارش مشکل، بازبینی و اصلاح خواهد شد.**
2. آزمون‌های جریان کامل: تقسیم، انصراف (تأیید/رد/انقضا)، درخواست تغییر اتمی، پیوستگی کیلومتر.
3. تأیید و رفع ابهام‌های پیوست پ (انصراف از Pending، لغو از WithdrawalPending).
4. بررسی RowVersion و Constraint در Migrationها.

## P1 — معماری
5. انتقال منطق از `MissionManagementService` (≈۱۵۸۰ خط) به Application و شکستن آن به سرویس‌های کوچک (ثبت، تأیید، تغییر، تقسیم، کیلومتر، انصراف). **در حال انجام؛ قواعد برنامه‌ریزی و قرارداد MissionChangeProposal به Application منتقل شده‌اند. سناریوهای ثبت، فهرست، شروع بررسی، رد و تأیید/اعمال پیشنهاد تغییر در PRهای شماره ۳ و ۴ و ثبت درخواست و بررسی اولیه مأموریت در PR شماره ۵ به Application منتقل شده‌اند.**
6. شکستن `FleetAuthenticationEndpoints` و فایل‌های بزرگ.
7. تغییر نام پروژه آزمون یا جداسازی آن به Domain/Application/Infrastructure/Integration.
8. کاتالوگ مرکزی مجوزها (ثابت‌ها) + ثبت مجوزهای مستقل مذکور در پیوست ب.

## P2 — قابلیت
9. به‌روزرسانی زنده تایم‌لاین/فهرست‌ها با SignalR.
10. تأیید/پیاده‌سازی ذخیره PDF حکم (RTL، فونت فارسی) و قالب قابل تنظیم.
11. نگاشت وضعیت‌های تحویل ADP پس از دریافت نمونه واقعی.
12. بازبینی ۸ گزارش و خروجی‌ها نسبت به بخش ۱۱.

## P3 — محیط واقعی
13. تست IIS + Windows Auth + LDAPS، ارسال پیامک واقعی، تست بار/امنیت، سیاست پشتیبان‌گیری (چک‌لیست `docs/deployment`).

## سابقه تغییر وضعیت
- **۲۰۲۶-۱۱-۰۱** — آزمون یکپارچه SQL و هم‌زمانی به درخواست کاربر به تعویق افتاد؛ بررسی در محیط عملیاتی انجام خواهد شد.
- **۲۰۲۶-۱۱-۰۱** — انتقال سناریوی تنظیم قواعد برنامه‌ریزی مأموریت به Application و آزمون‌های واحد مربوطه در PR شماره ۱ انجام شد؛ CI ویندوز و اوبونتو موفق بود.
- **۲۰۲۶-۱۱-۰۱** — قرارداد داده‌ای `MissionChangeProposal` از Infrastructure به Application منتقل شد؛ CI شماره 643 در Windows و Ubuntu موفق بود.
- **۲۰۲۶-۱۱-۰۱** — سناریوهای ثبت، دریافت، شروع بررسی و رد درخواست تغییر به Application منتقل شدند؛ تست‌های واحد سناریوها اضافه شدند. تأیید درخواست و اعمال پیشنهاد به‌دلیل وابستگی به اعتبارسنجی منابع، زمان‌بندی و کیلومتر در گام بعدی باقی مانده است؛ CI شماره 652 در Windows و Ubuntu موفق بود؛ Build، Unit Tests و Publish ویندوز همگی موفق شدند. چهار تست جدید پس از اصلاح fixture زمان تهران سبز شدند.

- **۲۰۲۶-۱۱-۰۱** — سناریوی تأیید و اعمال پیشنهاد تغییر به Application منتقل شد؛ اعتبارسنجی منابع و کیلومتر از طریق درگاه‌های Application و آداپتورهای Infrastructure انجام می‌شود. آزمون زمان پایان نامعتبر اضافه شد؛ CI شماره 654 در Windows و Ubuntu موفق بود.
- **۲۰۲۶-۱۱-۰۱** — ثبت درخواست مأموریت و شروع بررسی، تأیید و رد درخواست اولیه به سرویس‌های Application منتقل شدند. شماره‌گذاری جلالی و تراکنش Serializable در Infrastructure باقی ماندند؛ آزمون‌های واحد سناریوها اضافه شدند. CI این تغییر در انتظار اجرا است.
